🔄 Firestore Database Migration Tool

Safely copy all web data from your source Firestore project to your new target Firestore project.

⚠️ Important: Ensure Firestore Security Rules on New Project (`photoup-8fbb8`)

By default, new Firebase projects lock write permissions. If writes freeze, make sure your new project's Firestore Security Rules allow writes during migration:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

(Go to Firebase Console → Firestore Database → Rules tab → Publish)
